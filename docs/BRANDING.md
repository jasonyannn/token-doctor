# Branding

The supplied combined logo lives at `public/brand/logo.png`. The mascot crop lives at `public/brand/mascot.png`. Replace the files or change their paths in `components/brand/index.tsx`, updating image dimensions to match the new aspect ratios. `BrandLogo` renders the full logo or the compact mascot mark. `MascotAssistant` supplies the mascot in onboarding, help and diagnosis.

Replace `app/icon.png` for the browser icon. Update the metadata in `app/layout.tsx` if the logo path or product name changes.
