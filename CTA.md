# Token Doctor calls to action

Landing page actions open local test sign-up. Existing test users can switch to sign-in in the same form. After authentication, visitors go to the selected screen.

| CTA | Screen after sign-in |
| --- | --- |
| Get started | Overview |
| Explore demo | Overview, with the demo dataset on first use |
| Upload usage data | Settings, which includes CSV and JSON import |
| Investigate demo findings | Token Diagnosis |
| Open live simulator | Live Token Usage |
| Review demo recommendations | Recommendations |
| Sign out | Landing page |

The simulator starts when the visitor selects **Start**.
